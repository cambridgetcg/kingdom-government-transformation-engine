# Government Transformation Engine: United Kingdom

A zero-dependency, offline Phase-0 producer for static transformation orientation across the six planes of the KINGDOM UK Government Engine:

`Mandate → Jurisdiction → Law → Money → Delivery → Remedy`

The arrow is a reading aid, not automatic progression. Each dossier contains two separate graphs:

1. typed authority/accountability dependencies across the six planes; and
2. an explicitly hypothetical causal-change graph with BAU and distinct alternative paths.

All three dossiers are visibly synthetic, held, non-personal and not adopted. No preferred option exists. Human gates are required and incomplete. The producer has no network, runtime fetch, LLM, MCP, form, submission, decision, implementation or external-effect capability.

## Commands

```sh
npm test
npm run validate
npm run build
npm run build:check
npm run overview
npm run check
```

`build` writes only [`public/transformations.json`](public/transformations.json). It deterministically compiles [`data/config.json`](data/config.json), [`data/dossiers.json`](data/dossiers.json), the exact vendored Government Engine snapshot, and the single closed schema.

## Dossiers

- Public-money transparency information service: separates plans, forecasts, Estimates, appropriations, credit, issue, outturn, GBS, GOV.UK Pay and RTGS; labelled-pound tracing stays held.
- Four-nation public-service information proposition: keeps England, Scotland, Wales and Northern Ireland distinct behind a specialist competence-review hold.
- HMRC decision-notice explanatory-content redesign: keeps complaint, statutory review, tribunal appeal and judicial review parallel and determines no route, deadline, eligibility, liability or legal effect.

Read [`UK-GOVERNMENT-TRANSFORMATION-ENGINE-v0.1.md`](UK-GOVERNMENT-TRANSFORMATION-ENGINE-v0.1.md) for graph semantics, evidence handling, lifecycle and limitations.
